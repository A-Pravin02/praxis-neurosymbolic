# Reproducing the paper

Every number in `main.tex` is regenerated by the commands below, from committed inputs.
Nothing is copied by hand: runs append per-question rows, `research_report.py` recomputes
every metric from those rows, and `make_figures.py` renders every figure and table from
the report.

## What is frozen, and where

| Artifact | Path | Frozen at |
|---|---|---|
| Generator of companies | `backend/app/evaluation/worlds.py` | commit `b4e1bdf` |
| Reference oracle (gold answers) | `backend/app/evaluation/oracle.py` | commit `b4e1bdf` |
| Question templates | `backend/app/evaluation/casegen.py` | commit `b4e1bdf` |
| Development split (153 questions, worlds 11–13) | `backend/data/benchmark_worlds/dev.yaml` | commit `b4e1bdf` |
| Test split (255 questions, worlds 101–105) | `backend/data/benchmark_worlds/test.yaml` | commit `b4e1bdf`, before any system ran on it |
| World records and policy text | `backend/data/benchmark_worlds/world-*/` | commit `b4e1bdf` |

The rule files inside each world are *not* frozen: they are the system under test and are
copied from `backend/data/meridian/rules/` before every run. A test
(`test_the_frozen_test_split_is_committed_and_unchanged_by_regeneration`) fails if the
generator no longer reproduces the committed test split.

## 1. Validity of the gold answers

```bash
python scripts/check_oracle.py --json backend/data/benchmark_worlds/oracle_check.json
```

Expected: `ALL 3914 / 3914` agreement and `killed 12 / 12 mutants`. The script exits
non-zero on any disagreement or surviving mutant.

## 2. A language model

The model-based systems reach an open-weights model through a local OpenAI-compatible
server (needs CUDA PyTorch and `transformers`; `bitsandbytes` for `--4bit`):

```bash
python scripts/local_llm_server.py --model <path>/Qwen2.5-1.5B-Instruct
```

Every completion is cached in `eval_reports/llm_cache/<model>.sqlite`, keyed by the exact
messages and token limit; a re-run is served from the cache and reproduces the answers
exactly. The cache is the record of the raw model outputs the results were scored on.

## 3. Runs

Systems without a model (tag `deterministic`):

```bash
python scripts/run_research.py --split test --tag deterministic \
  --systems neurosymbolic neurosymbolic_lexical rag_extractive
```

Model-based systems, one tag per model:

```bash
LLM_PROVIDER=openai LLM_BASE_URL=http://127.0.0.1:8765/v1 LLM_MODEL=Qwen2.5-1.5B-Instruct \
LLM_TIMEOUT_SECONDS=900 python scripts/run_research.py --split test --tag qwen2.5-1.5b --workers 12 \
  --systems llm_only llm_rag llm_rag_selfcheck llm_rag_rules ns_parser ns_parser_llm \
            ns_parser_no_verification ns_parser_latest_version ns_parser_two_valued \
            ns_parser_trust_statements ns_parser_no_authorization
```

Runs are resumable: an interrupted run continues from the rows already written to
`eval_reports/research/<tag>/<split>.<system>.jsonl`.

## 4. Report, figures, tables

```bash
python scripts/research_report.py --split test      # docs/paper/results/test.json
python scripts/make_figures.py --split test         # docs/paper/figures/*
```

Only complete runs (every question of the split answered) are included in the report.

## 5. The paper

```bash
cd docs/paper && pdflatex main && bibtex main && pdflatex main && pdflatex main
```

## Protocol notes

- Development questions were used to find and fix faults in the system. Test questions
  were not inspected for that purpose, and every system change after the test split was
  frozen is in the git history.
- Decoding is greedy. Requests are batched on the GPU; batching can rarely change a greedy
  token through floating-point noise, which is why the completion cache, not re-generation,
  is the reference for reported numbers.
- Bibliographic entries in `references.bib` were entered from memory and must be checked
  against publisher records before submission.

## Latency: what the reported figures measure

The paper is exactly six pages and the column holding the experimental design has no
slack, so the protocol is stated here. Table II's latency column is the **per-question
mean of wall-clock time inside `NeuroSymbolicController.answer`**, on CPU, with no GPU.
It excludes process start-up, model download and knowledge-pack loading. It *includes*
the first question of each world, which also builds that world's goal catalogue and
policy index, and that question costs several times any other.

Three figures in the artifacts measure three different things, and they are easy to
mistake for each other:

| Figure | What it is |
|---|---|
| 77.9 ms | Table II, LLM-free. Mean over 255 questions, measured during a run of all 14 systems. Median 61.3 ms; the slowest case is 1421 ms, the first question of world 101. |
| 46.6 ms | The same system re-run alone with `--workers 1` (`eval_reports/research/latency-protocol/`). Accuracy and hallucination reproduce exactly at 0.796 and 0.149; only latency moves, because the published run shared a machine with the language-model systems. The published figure is therefore the conservative one. |
| 146 ms / 3.2 ms | The ten demo cases, first pass and repeat (`artifacts/demo_suite.json`). The encoder memoises embeddings by text, so asking the same question twice in one process is about forty times cheaper. Only the first pass is comparable to the two figures above. |

Regenerate the last of these with `python scripts/record_demo_suite.py`, which records
both passes and labels which is which.

## Models and inference stacks, per configuration

Reported separately because the paper's capability limitation turns on it: the 1.5B and
7B results do not share an inference stack, so a difference between them is not purely a
difference of model size.

| Configuration | Model | Role | Inference stack |
|---|---|---|---|
| PRAXIS (default, "LLM-free") | none on the decision path | — | deterministic realizer; bge-small 33M encoder via ONNX, CPU |
| PRAXIS + parser | Qwen2.5-7B-Instruct | semantic parser only; decisions stay symbolic | OpenAI-compatible local endpoint (`scripts/local_llm_server.py`) |
| `llm_only`, `llm_rag`, `llm_rag_rules`, `llm_rag_selfcheck` | Qwen2.5-7B-Instruct | answers the question | same endpoint as above |
| Scale comparison, Section XII | Qwen2.5-1.5B-Instruct | same roles as the 7B | Hugging Face `transformers`, greedy, CPU/CUDA (`LocalTransformersProvider`) |
| Relevance-gate measurement | Qwen2.5-1.5B-Instruct | semantic parser | `transformers`, as above |
| Study II | 19.9M decoder trained from scratch | generator under the gate | project code, see Section XI |

Decoding is greedy everywhere and temperature is 0.

## Independent re-verification

These commands were run and their results are what the paper and the change log report.
A reviewer re-running them is re-verifying, not taking the report's word:

```bash
python scripts/independent_metrics.py    # 151 values from raw records, 0 mismatched
python scripts/verify_claims.py          # 25 textual claims against the artifacts
cd backend && python -m pytest tests/ -m no_db -q    # 143 passed
powershell -File scripts/export_pdf.ps1 docs/paper/PRAXIS_IEEE.docx   # 6 pages
```
